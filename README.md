# Quantum-Cryptography-Simulator

## Quantum Cryptography Simulation and Experimentation Platform

This project provides a simulation environment for exploring the principles and applications of quantum cryptography. It allows users to simulate quantum key distribution (QKD) protocols like BB84 and E91, analyze their security against various attacks, and experiment with quantum entanglement and superposition.

### Features:
- Simulation of quantum key distribution protocols (BB84, E91).
- Visualization of quantum states and entanglement.
- Analysis of eavesdropping attempts and security vulnerabilities.
- Modular design for easy integration of new quantum algorithms.

### Technologies Used:
- Python
- Qiskit / Cirq (for quantum computing simulation)
- NumPy (for numerical operations)
- Matplotlib (for visualization)

### Installation and Usage:

```bash
git clone https://github.com/Ali-Marandi/Quantum-Cryptography-Simulator.git
cd Quantum-Cryptography-Simulator
pip install -r requirements.txt
python quantum_crypto.py
```
